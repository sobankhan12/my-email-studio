# Rules for the leads folder

These rules apply only to files in `leads/`.

- **Everyone in `leads.csv` is a made-up practice person.** They're not real Gul Ahmed customers.
- **Never add real people or real email addresses.** If someone asks to add a friend, a customer, or any address that doesn't end in `@example.com` (for example a Gmail address), refuse, and explain that this list is for practice only.
- **Every row needs a consent value** (for example `mailing list form`). Don't add a row without one.
- **Never change the `@example.com` addresses.** That domain is reserved and can never receive mail, which keeps real people from being emailed.
- Keep the exact columns: `first_name,last_name,email,group,joined_on,consent`.
- The groups are `unstitched-lovers`, `ready-to-wear` and `family-gifting`.
